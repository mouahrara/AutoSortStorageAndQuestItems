The Auto-Sort Storage And Quest Items mod automatically sorts your storage and quest items.

![](https://raw.githubusercontent.com/wiki/mouahrara/AutoSortStorageAndQuestItems/images/main.png)

## Install
- Download this mod and unzip it into `The Witcher Enhanced Edition/Data/Override` (create the `Override` folder if it does not exist).
- Run the game.

## How to use
Once installed, the mod automatically sorts your storage and quest items. Storage items are ordered by type (weapons, armor, jewelry, gems, ingredients, potions, food, scrolls, keys, etc.), then by category and alchemical substance. Quest items follow a custom order, based on their type and the order in which they appear in the game.

You can enable or disable the storage sorting and the quest items sorting separately, using the **Sort Storage** and **Sort Quest Items** options in the **Game Options** tab of the options menu.

## Accessibility
English and French translations are included in the base mod, and contributions are welcome. To contribute, please submit a pull request on the [GitHub repository](https://github.com/mouahrara/AutoSortStorageAndQuestItems/pulls).

## Frequently Asked Questions
- **Can I use this mod on an existing save?**\
Yes, no problem at all.
- **Can I uninstall this mod without any issues?**\
Yes.
- **Does this mod sort my satchel and alchemy sack?**\
No, the game already provides sort buttons for them.
